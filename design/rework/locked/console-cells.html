Design read

Reading this as: an always-on-top companion for one developer running several Claude Code sessions, in a monochrome cell-grid instrument language, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

  • ENERGY 2: one large dot-matrix figure per screen, everything else quiet
  • RHYTHM 2: blocks share one grammar (label, cells, scale), with the spend block and the question box as deliberate breaks
  • MOTION 1: hover states only, plus one blinking cell on the agent that is working right now. It stops for reduced-motion

One-line reasons

  • Cells: counting beats reading a bar. "10 of 30 cells" is the same at a glance from across the desk
  • Context grid in two rows of 15: the second row is the hand-off zone, so filling it is the warning
  • Hatched cells for estimated cost: exact and estimated dollars stay visibly different, never summed silently
  • Orange as the only accent: it means "you", so it can never be ignored as decoration
  • Dark first: it sits beside a dark VS Code all day. The light theme is kept and works
  • Doto for one figure per screen: it is the identity motif from the bio log reference. Cascadia Mono for all other figures, because it is already the app's data face and tabular. Segoe UI for titles because it reads as part of Windows
  • Uppercase labels at 0.04em, not wide tracking: they separate labels from values without shouting

Anti-slop pass on the earlier drafts

  • Sample numbers are now labelled as sample data (R-17, R-38)
  • Empty, loading, error and offline states added (R-27)
  • No eyebrow pill above the heading, no coloured left stripes, no blue accent (Direction B had stripes)
  • State never by colour alone: glyph, word and the "needs you" square
  • Palette: off-white ink plus orange, with red and green kept for state only (R-29)

Before building

  • Doto would ship as a local woff2 in web/ (OFL licence); the app makes no network calls
  • Same open checks as Rings and Pill: frameless resize on Windows, estimated cost from transcript usage, per-minute activity buckets
  • The cells are plain CSS grid; no library, no build step
