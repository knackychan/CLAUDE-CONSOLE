The distinction

Task overviewStep chatGlobal Super Agent
The task goal, progress, latest summary, supervisor approvals, result acceptance and step list. Each step opens its chat. No chat composer is shown here.One chronological conversation for the selected step. You, the task agent, expandable inline tool calls and their results. One fixed recipient at the bottom. Completed steps are read-only; planned steps have not started.The existing global conversation stays in its own pane. Its input and draft do not become the selected task or step’s input.

The previous expanded task stacked a step preview, a step list and another task conversation. That layout is removed. The current-step conversation now owns the full chat view. The dashboard shows a bounded excerpt from the same ordered events, with command status and output age.

What to try

  1. Open Cache product thumbnails. The default view is Task overview. Open chat on step 03, or choose the Step chat tab.
  2. Use Play sample stream. Agent text streams, a completed edit appears inline, and the active spinner moves to the executing test command. Expand a completed tool call to inspect its result. Scroll up; new events do not pull you away while reading earlier messages.
  3. Write a step draft. Switch to overview, inspect another step, and return to step 03. The draft remains bound to T-031 · step 03. Completed and planned steps do not inherit its input.
  4. Use Reply in step 3 chat on the import task. The question appears as the agent’s message and the scoped answer composer is at the foot of that same chat.
  5. Use Running previews to compare an active command with the caption task’s quiet process. “No output for 3m” does not claim the process is stuck.
  6. Switch dark/light and desktop/narrow sizes. On narrow screens, Supervision and Tasks still have explicit views; task overview and step chat remain separate within Tasks.

Refresh or Reset sample clears this tab’s drafts and simulated actions. With reduced motion enabled, playback starts paused and active status remains legible without rotation.
