The merge

PieceFromWhy
Folded pill, peek card with inline answerASmallest footprint; one click to answer
Session rings (context fill, state glyph, badge)CNow the pill's content too: names-free but distinct per task
Rail + focus pane as the open windowCOne task big, the rest at a glance
Overview as 2-line cards, Lanes as a toggleA + CCards to triage, lanes to see time and cost
Palette: quiet graphite, amber = youAFollows the system theme; only attention is loud
4-cell stats strip, doing-now line, burn rateA + CCost and progress readable at a distance

Dropped

  • C's 64 px rail-only strip: one folded form (the pill) is enough, and it is one less window size to test
  • A's separate Session page: the focus pane replaces it
  • C's dark-only look: the window follows the system theme

Window states

Pill
380 x 46, rounded, docked to an edge; double-click opens
Peek
Pill + one card, opens by itself on a new question, blocked or failed task
Open
400 x 640 (min 360 x 420); rail 56 px + pane; double-click a top bar folds
Frame
Borderless; drag from the pill grip, the rail's empty area or the pane's top bar
Memory
Position, open/folded and selected task kept in config.json

Human-proof rules

  • A ring is never alone: glyph inside, badge outside, tooltip with state and title, and the state in words once opened
  • The pane follows a task that just started asking, unless you picked one in the last 2 minutes
  • Past 6 rings the pill shows "+3"; Done tasks leave the pill and rail and live in Overview
  • Stop confirms in place; close says runs continue; Up / Down walks the rail, Enter opens, Esc goes to Overview, then folds
