Design read

  • Dials: ENERGY 2, RHYTHM 2, MOTION 1. Motion only on running marks and button presses, none on keyboard moves; all of it off with reduced motion or Windows animation effects off.
  • One count: the header button, the super agent row, the page pill and the project lines all count items that reach you; a batch card counts each member.
  • A card is self-contained: project and task, kind and age, the ask, the facts code knows, the options with the default, then the super agent's words in their own block (◆ Super agent). Its words never read as a fact, and a card it could not check says so instead of looking approved.
  • What cannot wait says so: "always yours" items and a decision whose default is about to be taken have no Later; the card says why it stays.
  • Later is never a hiding place: each line has its reason and its return time; while sorting is paused, off, over its limit or failed, the super agent's Later items come back to For you.
  • Unranked keeps every action: paused, off, limit and failed differ only in their state line; the cards keep their options and buttons, batches split, recommendations go.
  • Roll-up: a quiet project is one line; a project with something for you shows those rows and one "more" line; steps only under the selected task.
  • The box always names where Enter goes: New work, Super agent, Answer, Task, or read only for an observed chat.
  • Orange means for you, nothing else; red and green only for state. No eyebrow, glyph or token is new except the hatched mark for "not seen".

Decided by Fred, 2026-11-08

  • The current card is orange-tinted like the dock card (not neutral with orange only on its primary button).
  • The recommendation is a neutral block headed "Super agent suggests" (not one muted ◆ line under the ask).
  • Later by hand is one fixed hour (no choice of return times).
  • With nothing selected, New work goes to the last project used (the box does not ask for a project).
  • A card the super agent could not check has Open the task as its primary button; Accept stays a plain button.
