Rules behind the buttons

  • Run always starts a new session (one task = one chat). Continue resumes it with your follow-up.
  • Escalate appears after a FAIL verdict: one step up (effort first, then model), once per task; it writes the routing-misses line.
  • Handoff runs /session-handoff in that session, then marks it ended. Gauge red (60%+) or 2 follow-ups makes it the highlighted button.
  • Open in terminal opens a new terminal in the project folder with claude --resume <id> (for blocked actions, or to take over).
  • Chat tab shows the streamed text for window-started runs; VS Code / terminal sessions show steps only (you already see their chat there).
